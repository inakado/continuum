## Цель и scope

Проверить working tree относительно `HEAD` 3a3bd57, включая untracked исходники: банк/конструктор/назначения/отзывы/автосохранение/фото/проверки/статистика, общие hover/focus/dialog/search, auth и аддитивные миграции. ## Порядок

1. Два read-only code-review: Standards и Spec. Основной агент — интеграционные проверки, UI/UX и загрузка данных.
2. Shared/web typecheck/test/lint/build; Docker API build/unit/full integration, readiness/smoke. Ошибки отделять от ограничений окружения, воспроизводить до исправления.
3. Встроенный браузер: teacher/student desktop и выборочные mobile, hover/focus/меню/диалоги/пустые состояния/переходы. Не менять реальные ответы/материалы для тестов; только изолированные временные данные.
4. Проверить query/pagination/detail/polling и изучить актуальные первичные рекомендации. Крупные оптимизации — отдельный измеримый шаг после проверки, без переписывания кода на предположениях.
5. Выполненное вынести в completed-историю; активные/deferred roadmap и debt оставить с реальными незавершёнными пунктами. Индекс/ссылки/SoR синхронизировать.

## Граница выпуска

Проверка не является production deploy. По deploy/README требуется отдельная явная команда владельца; перед выпуском нужны точный commit, утверждённые миграции, чистый серверный Git, резервная копия и live smoke. Никаких reset/force push/destructive DB операций. Доступ на production проверяется только read-only при необходимости.

## Критерии готовности

Подтверждённые блокирующие дефекты устранены и проверены; результаты каждого слоя зафиксированы, ограничения названы. Не обещать «никаких багов/лагов» по одному зелёному тесту. Остаток roadmap содержит только будущую работу; история доступна отдельно.
