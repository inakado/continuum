# Дата загрузки и компактный банк

Статус: Completed.

Цель: показывать дату первого добавления задачи, фильтровать календарём и уместить рабочую область в окно ноутбука. Раскрытое условие занимает отдельное белое полотно с хедером, сворачиванием и переключением задач.

Scope: Assessment Bank, shared transport и teacher-bank. Без миграций, student UI, изменений содержимого банка, push/deploy и постороннего working tree.

Порядок: расширить read-контракт и единый предикат списка/экспорта; подключить календарь и URL; уплотнить область и раскрытие; проверить тестами и браузером; обновить SoR.

Решения: `createdAt` задачи — первое добавление, обновление версии/восстановление дату не меняет. Нативный календарь задаёт полуоткрытый UTC-интервал `uploadedFrom` / `uploadedBefore` по локальному дню браузера, включая переходы часового пояса. Пустой фильтр не ограничивает дату.

Риски: длинные условия и большие списки требуют внутренней прокрутки; не обрезать содержание. Старый API может не отдавать дату, поэтому transport-поле добавляется optional для совместимости с preview и поэтапным обновлением.

Готовность: даты и календарь работают вместе с фильтрами/экспортом/историей; раскрытие скрывает банк; десктоп не требует прокрутки страницы для кнопок; мобильный layout без горизонтального overflow.

Проверки: shared tests/typecheck, API unit/integration и Docker typecheck, frontend boundaries/typecheck и teacher-bank tests, desktop/mobile браузер.

Результат: контракт/list/detail/export, календарь и URL, дата в списке и внизу сведений реализованы. Пакет `output/kinematics-no-projectiles-v1/kinematics-rpd-rud-corrected.zip` импортирован через реальный локальный UI: 30 новых задач; фильтр 13.11.2026 возвращает 30, прежние 6 задач сохранены.

Проверено: boundaries; web/shared typecheck; 86 frontend-тестов банка и подбора, 84 shared, 113 API unit и 2 integration по темам/границам даты; Docker typecheck; docs:check и diff --check. Браузер: 1440×820 и 1710×950, мобильный 390×844 и раскрытие 320×740; горизонтального overflow нет, desktop и раскрытое mobile-полотно укладываются в viewport. Reload сохраняет календарь, раскрытие/сворачивание — список и выбранную задачу. Длинные условия/раскрытые сведения прокручиваются внутри. Скриншоты — `output/playwright/bank-*`.

Локальное окружение: API на localhost:13000 (`continuum-bank-qa-13000`), web на localhost:3001; порт 3000 занят другим сервисом. Установка зависимостей и миграции не выполнялись. Во время CSS HMR возникла ошибка Next.js `removeChild`; после чистой перезагрузки и повторного desktop/mobile-прохода ошибок страницы нет.

Проверка ponystack-contract: нативный input date без зависимости, прежний предикат списка/экспорта и существующий split layout; удалены неиспользуемый импорт Link и мёртвый CSS.
