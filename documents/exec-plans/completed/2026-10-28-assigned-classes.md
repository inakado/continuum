# Получатели назначения у заголовка работы

Статус: Completed, локальная реализация без deploy.

## Цель и границы

Убрать accordion назначенных классов между фильтрами и таблицей выполнения. Сохранить контекст получателей, существующие запросы удаления/подтверждение и видимое действие добавления учеников. Только teacher assignments UI; API, БД и student UI не меняются. Основание — [исследование](../../research/2026-10-28-assigned-classes-ux.md), согласованное пользователем 28.10.2026.

## Реализация

- `AssignedClasses` перенесён в группу заголовка. Один/два коротких уникальных класса видны по названиям, остальные — числом классов. Общая численность относится ко всей версии. Счётчики строк строятся одним проходом по историческим получателям.
- Список — существующий Radix Dialog в немодальном режиме: привязанная панель desktop, нижняя панель до 80dvh на телефоне. Нет формы с несохранёнными изменениями; немодальность сохраняет закреплённую шапку и допускает закрытие взаимодействием с фоном. Существующий диалог необратимого удаления остаётся модальным.
- Перед подтверждением список закрывается. Безопасный начальный фокус — «Отмена», возврат после закрытия — к сводке. Сохраняются membership hash, pending guard и переход после последнего удаления. Подписи уточнены до «Удалить назначение».
- При одном классе фильтр скрыт. Hook нормализует избыточный или исчезнувший class через replaceState, сохраняя остальные параметры и страницу. Поиск, статус, фото и выбранный класс не меняют сводку назначения.
- Русские подписи учеников/классов вынесены из существующей формы в `assignment-labels` для двух потребителей. Ненужные accordion CSS удалены. Новых зависимостей нет.
