# UI исправления и типографика архива

Статус: Completed. Локально реализовано и проверено; production не менялся.

Цель: облегчить окно точечного исправления на desktop/mobile и устранить `---` в условиях после конвертации TeX. Область: teacher-bank UI, общий Markdown read-path для сохранённых условий, локальная сборка архива и гайд. Ключи, ответы, баллы и серверный correction-контракт не меняются.

Решения: сравнивать только условие/варианты/рисунки; убрать фиктивные поля ввода и дубли сведений. Сократить повторяющиеся пояснения и скрыть внутренний ID. Использовать состояния общих кнопок. Корень `---`: Pandoc writer `markdown` с smart по умолчанию записывает длинное тире тремя дефисами. Новый writer `markdown-smart` сохраняет Unicode-тире; legacy fallback разрешён только отдельному `---` в обычном текстовом узле, формулы и Markdown-разделители не меняются.

Порядок: локализация → ограниченные правки → component/shared проверки → desktop/mobile/keyboard/overflow → пересборка ZIP/PDF и контроль ключей/формул → гайд и завершение.

Риски: автоматическая типографика не должна менять минусы, диапазоны и кодовые ID; нужны регрессионные тесты. Изменения остаются локальными, production вне scope. Откат — предыдущий код и архив; исходник на Desktop не редактируется.

Готовность: понятные начальное/preview/error/pending/success состояния, нет лишних ответных контролов и источников в сравнении, фиксированные действия доступны на мобильном экране; сохранённые `---` читаются как тире, новые ZIP не содержат таких артефактов в прозе. Shared/web тесты, boundaries, typecheck, docs:check, визуальный просмотр.

## Результат

- Убраны технический ID, повторы пояснений, поля ответа и два повторяющихся блока учительских сведений в сравнении. Остаются исходное/исправленное условие, рисунки и варианты. Начальное/успешное окно компактнее; широкая форма нужна только сравнению. До preview нет неработающей кнопки сохранения.
- Кнопки используют catalog-action с согласованными hover/focus/disabled. Мобильные действия у нижнего края, длинное имя ZIP не расширяет строку, цель checkbox/download не меньше 44 px.
- По дополнительному скриншоту выявлена общая причина значков: DropdownMenuItem был строчным, gap у deleteItem не работал. В базовом UI-kit заданы flex/align-items/gap и несжимаемый SVG. Это оправданная общая правка для меню обеих ролей; собственные feature-контуры других ролей не менялись. У taskMenu исправлено имя токена скругления. В полном банке 12 видимых SVG-контролов имеют вертикальное смещение центра 0 px; оба пункта меню — 44 px и gap 10 px.
- Pandoc воспроизведён на минимальном примере: writer markdown сохранял Unicode-тире как `---`, markdown-smart выводит `—`. Общий parser поддерживает старое отдельное `---` только в текстовых узлах; math/ID/диапазоны/экранированные дефисы не меняются. В сборке отключён smart writer и добавлена проверка оставшихся TeX-тире в прозе.
- Пересобраны основной ZIP, отдельное исправление №16656 и PDF. Сравнение ZIP выявило ровно 3 изменённых файла (4 тире) у №16656/13416/159585: все формулы, grading, maxPoints, метаданные и картинки прежние. 201 формула сверена с AST и MathJax, ошибок нет. Все 31 страницы PDF совпали по пикселям с ранее просмотренным рендером при 35 dpi.
- 70 shared, 94 API unit, 277 frontend тестов полного web-набора прошли; затем дополнительный связанный тест menu → correction → Escape/возврат фокуса прошёл вместе с 4 тестами correction. Typecheck web/shared, boundaries, docs:check и diff --check пройдены.
- В браузере проверен настоящий TeacherBankScreen с его header/навигацией/фильтрами/списком и CSS/шрифтами приложения; fixture HTTP и адаптер Next navigation изолируют данные. Это не production/auth smoke. Начальное/preview состояние, настоящая загрузка одиночного ZIP, меню и клавиатура, источник/тире/варианты всех трёх изменённых задач проверены на desktop; диалог также на 375×812, 375×568 и ширине 768.
- Прежняя временная оболочка со служебными неоформленными кнопками была показана пользователю как фон QA и вызвала обоснованное замечание; заменена полным feature-экраном. Финальные снимки показывают рабочие компоненты. Временный сервер остановлен, каталоги удалены, вкладка закрыта.
