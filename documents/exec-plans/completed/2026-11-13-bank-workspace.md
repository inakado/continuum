# Основной банк с независимой областью чтения

Статус: Completed.

Цель: перенести принятый пользователем прототип в `/teacher/bank`, сохранив исходные операции и дату первой загрузки.

Scope: teacher-bank, ранее подготовленные read/API/shared изменения даты, профильная документация. Без student UI, правок библиотеки/навыков, push и deploy.

Порядок:
- Исправить hover «Показать задачи» и отступы шевронов до переноса.
- Перенести компоновку, фильтры и раскрытие в production feature; убрать служебную ссылку и временный route/каталог.
- Сверить поиск, тему, дату, тип/ЕГЭ/источник, URL, экспорт, импорт, исправление, удаление/массовое удаление и отмену, раскрытие и мобильный возврат.
- Проверить web/shared/API и production web build; пройти реальные сценарии на локальном банке.
- Обновить SoR, удалить только артефакты данного прототипа, создать ограниченный коммит.

Решения: прежние API/query hooks и компоненты мутаций сохраняются. Общие фильтры выбора в конструкторе не меняют компоновку. Чёрные «Ответ / Метаданные» открывают один блок с автопрокруткой и reduced motion. Hover основного действия остаётся синим, шеврон select отстоит на 12 px.

Риски: смешанный working tree требует отдельного состава коммита; нельзя включать несвязанные изменения документов. Общая локальная БД сохраняется, QA-мутации допустимы только для созданной тестом задачи. Длинные условия требуют внутренней прокрутки.

Критерии завершения: основной route повторяет принятый UI, временный route отсутствует, исходные операции проходят проверки, документация соответствует коду, коммит содержит только банк.

Проверки: 479 web tests; 84 shared tests; 113 API unit tests; 15 integration tests банка; boundaries; web/shared и Docker API typecheck; docs:check; diff --check. Отдельный снимок только изменений банка: 135 тестов банка/конструктора/массовых действий и production build под Node 24.14.0 прошли. В production-списке маршрутов есть `/teacher/bank`, временного bank route нет.

Браузер: 1437×813 и 390×844; область условия 597 px на desktop. Проверены дата/reload (13.11.2026 → 30 задач), фильтры, исправленный hover и шевроны 12 px, раскрытие и автопрокрутка метаданных, навигация, сохранение прокрутки списка и мобильный возврат. В отдельной QA-задаче реальным UI проверены импорт, скачивание одной задачи, исправление до версии 2 с сохранением даты, экспорт по фильтрам, удаление и отмена, массовое удаление и отмена. QA-запись удалена с проверкой точного ID; исходные 36 задач сохранены. Временный route возвращает 404. Итоговые снимки — `output/bank-qa/`.

Очистка: удалены route/каталог прототипа, его README, служебная ссылка, мёртвые стили прежнего экрана и временные ZIP/снимки вариантов. Общие `BankFilters`/`BankExtraFilters` нужны конструктору и сохранены.

Task-specific troubleshooting: Turbopack требует, чтобы зависимости не выходили symlink за файловый root отдельного снимка; для проверки применена APFS clone-копия node_modules без установки. После удаления временного route удалён только его устаревший generated type из `.next/dev/types`, затем web typecheck прошёл. Production build проверен в отдельном каталоге, работающий dev-сервер не затронут.

Результат: принятая компоновка стала основным банком; исходные операции сохранены. Коммит формируется из отдельного снимка, в общих документах включаются только bank-разделы. Несвязанный working tree библиотеки и навыков не меняется. Push и deploy не выполняются.

Проверка ponystack-contract: перенесены действующие компоненты без новых зависимостей; API/мутации и общий Markdown не дублируются, старый временный контур удалён.
