# Импорт и проигрывание интерактивных лекций

Статус: Completed.

## Цель и контекст

Перенести согласованный KIN-01 из локального прототипа в библиотеку: общий расширяемый проигрыватель, проверяемый ZIP с содержанием и исполняемыми демонстрациями, предпросмотр учителя и открытие опубликованной версии учеником. Сохранить текст, визуальный язык и взаимодействия образца.

## Scope

- Shared v1-контракт пакета и ограниченного обмена сообщениями.
- Проверка ZIP до сохранения/публикации; защищённая выдача неизменяемой версии.
- Общая шапка/навигация/масштаб в приложении, статья и модели в opaque-origin sandbox.
- Переиспользуемый локальный authoring runtime и первый самодостаточный ZIP KIN-01.
- Teacher preview, student material links, scoped browser-local самопроверка.
- Тесты границ безопасности, импорта/доступа, поведения и desktop/mobile вёрстки.

Вне scope: production deploy, конструктор сцен в браузере, серверная сборка исходников, оценки/аналитика самопроверки, синхронизация прогресса между устройствами.

## Этапы

1. Сверить действующий прототип и storage/publication контур. Зафиксировать контракт.
2. Параллельно реализовать backend/shared, authoring/ZIP, teacher/student integration; общий host и протокол — основной агент.
3. Собрать KIN-01, выполнить реальный локальный импорт/предпросмотр/публикацию в изолированных тестовых данных.
4. Проверить сходство с прототипом, модели, навигацию, масштаб, память вопросов, изоляцию и права.
5. Обновить SoR, проверить сборки/тесты и передать ZIP с фактическими ограничениями.

## Decision log

- v1: ZIP содержит ровно manifest.json и самодостаточный lesson.html. Скрипты, стили, шрифты и геометрия собираются локально; загрузка новой лекции не вызывает deploy.
- Исполняемый код находится только в iframe sandbox="allow-scripts", без allow-same-origin и доступа к сессии. CSP ограничивает внешние запросы. Host принимает только типизированные сообщения от своего iframe.
- Шапка и профиль — действующие компоненты приложения. В пакете нет авторизации и копии профиля.
- Существующая модель LessonArtifact достаточна; миграция БД не планируется. Ранее загруженные непроверенные ZIP не должны становиться доступными ученику.
- Общие паттерны выносятся по первой реальной лекции; универсальная декларативная система физических моделей не вводится.

## Риски и восстановление

- Разница среды standalone/Next.js и MathJax может изменить переносы; требуется проверка завершённого рендера на нескольких ширинах/масштабах.
- Sandbox запрещает localStorage пакету: host хранит только ограниченное состояние конкретного пользователя/лекции/версии вопроса.
- Архивы ограничены compressed/unpacked budgets и hash; пакет не считается доверенным даже после проверки структуры.
- Не менять существующие PDF, доступы, черновики или чужой working tree. Ошибочный импорт не создаёт активную версию; предыдущий материал сохраняется.

## Критерии завершения и проверки

- Один и тот же ZIP проходит действующий parser и настоящий authenticated upload → teacher preview → publish → student read.
- Запрет чужого/неопубликованного материала подтверждён тестами. Пакет не читает cookie/storage родителя и не выполняет сетевые запросы.
- Все семь сцен и полный текст KIN-01 сохранены; работают scroll/navigation/scale/questions/reload и mouse/touch playback.
- Shared/API/web tests, boundaries, typecheck, документация и сборки проходят. API build/typecheck выполняются в Docker.
- Фактические команды, результаты и ограничения фиксируются ниже.

## Прогресс

- Старт: проверены prototype и действующие Library/Assets; работа разделена на три независимых контура.
- Реализованы shared ZIP/bridge контракты, ограниченный parser, защищённые read-path, атомарная публикация, teacher preview/student route, общий host и authoring kit.
- KIN-01 использует один Content в прототипе и пакете; ZIP включает весь код/стили/шрифты/MathJax CHTML и семь сцен. Сборка `pnpm lesson:build` воспроизводима. Конечный SHA-256: `5cfe427d8d00be957467ce1503c9ad3223530207a7b3db86164d4d5223bc9774`, 958 969 байт.
- На реальном sandbox исправлены зависимости от Next/Node, масштаб MathJax, порядок CSS при80%, закрытие меню при клике в iframe и native-submit самопроверки без добавления allow-forms.
- Подробная [сверка с прототипом](../../research/2026-11-06-interactive-prototype-parity.md): 16 пар/32 страницы, 4064 измерения формул, 64 перехода, 25 состояний моделей; вопросы/reload, touch, play/pause/replay/offscreen и изоляция прошли. Существенных расхождений в проверенном контуре нет.
- Проверки: web — 97 файлов/411 тестов, shared — 17/82, API — 29/113; HTTP/PostgreSQL/S3 — 2 файла/8 тестов с конечным ZIP; boundaries, typecheck, Docker API build, production web build, docs и diff-check — успешно.
- Временный QA-раздел, занятие, все версии/файлы и два тестовых аккаунта удалены после сверки. Файлы с тестовыми credentials удалены. Пользовательские данные сохранены. Production deploy не выполнялся.
- После приёмки убраны временные скриншоты, сырые QA-отчёты, одноразовые скрипты, дубли сборки и логи этой инициативы. Исходники, тесты, документация и конечный ZIP сохранены; в AGENTS добавлена прямая инструкция чтения контракта пакета.
- Deferred roadmap сверён с реализацией: LIB-05 закрыт, в LIB-04 оставлены только не реализованные выбор прежней версии и publish CLI; устаревшее утверждение об отсутствии ученического проигрывателя удалено.

## Итоговые ограничения

- Chrome desktop/mobile emulation; физические устройства, Safari/Firefox и учебная эффективность не проверялись.
- Host обновляется централизованно; изменение встроенного authoring runtime требует новой версии пакета. Произвольный динамический TeX вне начального Content требует расширения renderer.
- ZIP/hash перепроверяются на каждом чтении; отдельного cache нет. Самопроверка локальная, с разделением по пользователю и ревизии вопроса, без межустройственной синхронизации.
