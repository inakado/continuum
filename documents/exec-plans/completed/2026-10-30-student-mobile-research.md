# Исследование мобильного интерфейса ученика

Статус: Completed (исследование и временные прототипы, без изменения рабочего UI). Дата: 30.10.2026.

## Цель и scope

Пользователь просит сначала источники и UI/UX-анализ, затем текущие скриншоты и интерактивные варианты. Приоритет — student materials и основные ученические сценарии с телефона; teacher materials вторичны. Разрешена локальная демонстрация, не production-реализация выбранного направления, commit/push/deploy или запись в настоящие работы.

## Решения

- Исследованы первичные Apple/Google/W3C/Shopify источники. Применены ponystack, prototype UI и impeccable product/adapt: существующая типографика/цвета/шапка, списки без декоративных карточек; три композиции вместо косметических вариаций.
- Изолированный Vite вместо изменения защищённых Next routes: baseline монтирует настоящие student features на синтетических данных; предложения живут рядом в явно временном student-mobile-prototype. Это сохраняет текущий рабочий UI и позволяет безопасно сравнить его с A/B/C без auth и мутаций production.
- API и Next/auth adapters только в dev entry; ложного production API нет. Настоящий MathJax/локальные шрифты используются и в baseline, и в предложениях.
- Нет новой библиотеки/PDF-движка/службы, данных/миграций/нового workflow. Сохранение/завершение прототипа не доказывают реальные гарантии backend.
- Учительский пакет предыдущего задания не тронут. Источники, измерения, границы и рекомендации — в [исследовании](../../research/2026-10-30-student-mobile.md).

## Прогресс и проверки

- Сначала пользователю изложены источники и четыре принципа, затем показаны реальные student-компоненты и построены варианты A/B/C.
- Baseline: материалы, занятие, список работ, смешанная работа, фото решения и подтверждение. Снимки сохранены вне Git в visualizations текущего чата.
- Во внутреннем браузере проверены поиск и возврат к запросу в A, раскрытие B, переход к занятиям C, ввод −12 → карта → №23, открытие подтверждения с 17 пропусками. Пример с формулой: MathJax вывел 6 контейнеров без alert, поле ответа baseline y≈931px, B y≈513px. На 360px B: document width=scrollWidth=360, PDF touch targets 44px; нижняя панель на y=635 при высоте окна 700.
- `pnpm --filter web typecheck`, `pnpm lint:boundaries`, `pnpm --filter web test features/student-library features/student-works`: 9 файлов, 48 тестов passed. Проверялись существующие student-регрессии, тесты одноразового JSX не добавлялись.
- `pnpm docs:check`, `git diff --check` passed; Vite build во временный каталог прошёл. Предупреждение bundle >500kB относится к объединённому сравнительному стенду (579kB), не меняет рабочий Next bundle; отдельная оптимизация одноразового прототипа не выполнялась.
- В конце инструменты браузера изменились, локальное управление IAB стало недоступно: browser runtime вернул «Local browser use is disabled in Work settings». Повторный проход после последних небольших изменений (history Back, подписи количества, демонстрационный результат/вводный экран) не объявляется проверенным в браузере; они прошли сборку. Для показа отправлено открытие галереи через open_in_codex, результат queued, не подтверждение визуального открытия.
- Стенд оставлен доступным на 127.0.0.1:5184 для выбора; build-каталог удалён. Кеш около 10MB лежит в /tmp, удалить вместе с прототипом после внедрения. Production код и предыдущий teacher working tree сохранены.

## Риски и откат

Прототип показывает композицию, не готовый выпуск. Физический iPhone/PWA, клавиатура/поворот/safe areas, реальный PDF, камера и HEIC не проверены. Нижняя панель B должна отдельно проверяться с клавиатурой и на длинных условиях. Для реализации сохранить safe-leave, автосохранение, восстановление входа, photo queue и оценки.

Откат — удалить только новые student-mobile-prototype/config/script и исследовательские ссылки. Предыдущий working tree сохранить. После выбора и реализации удалить прототип и кеш; без отдельной команды не публиковать.
