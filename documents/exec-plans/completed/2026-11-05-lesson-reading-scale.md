# Масштаб чтения интерактивного KIN-01

Статус: Completed.

## Цель и scope

Реализовать согласованный контрол «− 100% +» справа от контекста занятия. Меняется типографика текста и формул с реальным переносом, ширина статьи сохраняется. Шапка, управление демонстрациями и панель вопроса сохраняют обычный размер.

## Порядок

- [x] Контрол, сброс, localStorage и ограничение 80–120% / 90–120% на телефоне.
- [x] Согласованное изменение размеров текста, подписей блоков и MathJax.
- [x] Сохранение позиции чтения и состояния демонстраций.
- [x] Проверки диапазонов, переноса формул, storage, клавиатуры и вёрстки.

## Решения и риски

Состояние изолировано в client-контроле: серверное содержимое не пересоздаётся при смене масштаба. Общий renderer MathJax отслеживает также смену кегля в ResizeObserver; это применимо обеим ролям и требует регрессионной проверки. Никакого transform/zoom для статьи. Откат ограничен изменениями данного прохода.

## Проверки

Unit/component tests для контроллера, font-only resize MathJax, lint:boundaries, web typecheck, релевантные tests, docs:check и browser QA всех масштабов на телефоне/desktop.


## Результат и проверки

- Контрол без внешней рамки, по последнему уточнению пользователя. Процент сбрасывает к 100%; пределы и disabled-состояния соответствуют текущей ширине.
- 8 component tests: шаги/оба предела/сброс, сохранение и адаптивный clamp без потери desktop-выбора, 5 невалидных значений storage, недоступный storage. В regression test общего MathJax проверен font-only resize при неизменной ширине.
- Browser QA: 21 состояние масштаба на 320/390/600/760/1440 px. Нет обрезания, горизонтальной прокрутки и ошибок MathJax; сохранены 19 формульных номеров. Разложение радиус-вектора перенесено по слагаемым, чтобы помещаться при 120% на 320 px.
- На desktop при 80% первый абзац занимает 3 строки вместо 4, колонка остаётся 960 px; ширина контрольной формулы меняется пропорционально 80/100/120%.
- Проверен возврат после reload и переход 80% desktop → 90% phone → 80% desktop. Enter/Space работают; размер и текст незавершённого ответа сохраняются.
- Позиция абзаца и формул после смены масштаба сохраняется с отклонением менее 0,3 px. Положение точки и время приостановленной демонстрации сохранены.
- lint:boundaries, web typecheck, 67 tests / 16 files прошли. Исходный TeX/PDF и основной интерфейс обеих ролей не изменены; изменения локальны.
