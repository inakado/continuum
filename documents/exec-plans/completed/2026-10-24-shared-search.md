# Единое поле поиска

Статус: завершено локально, без commit/push/deploy.

## Цель и границы

Вынести проверенный поиск банка в role-neutral `components/ui/SearchField` и подключить все семь существующих поисков teacher UI: банк, ученики, список работ, выбор заданий конструктора, назначения, отчёт, ученики подключения агента. Не менять запросы, URL/storage, правила фильтров, глобальные токены, страницу входа и student-экраны.

## Решения

Компонент контролируемый, без копии value и debounce: label, value, onValueChange, placeholder, maxLength, disabled, className и необязательный inputRef. Последний сохраняет возврат фокуса из действий со списком работ. Одна внешняя рамка focus-within, radius 2, скрытый нативный cancel и своя клавиатурная очистка. Пустая кнопка disabled/hidden с сохранённым местом; busy отключает input и очистку. Размер шрифта 16 на мобильном. CSS ограничен компонентом и специфичнее существующих общих правил feature input, чтобы они не возвращали внутреннюю рамку/отступы. Layout остаётся у features.

## Готовность и проверки

Нет прямых type=search вне общего компонента в production feature-коде. Общие component tests: Tab/Enter, очистка, фокус, отсутствие submit, disabled, maxLength, внешний ref. Существующие feature tests, typecheck, boundaries, lint, build, документация; browser desktop/mobile всех семи контекстов с проверкой computed styles и поведения. Исходный пользовательский ввод при QA не затрагивается.

## Риски и откат

Общий UI-kit изменяется по явной общей причине. Каскад feature CSS, label с кнопкой и восстановление внешнего ref проверяются отдельно. Данные сервера не меняются; откат только компонентов, адаптеров и их документов, без остального working tree.

## Прогресс

- Все семь поисков используют SearchField; rg подтверждает, что единственный production `type=search` находится в нём. Локальные стили поиска банка удалены, повторные правила мобильного шрифта из feature CSS убраны.
- Web 191/191, web typecheck, boundaries, scoped ESLint, финальный production build Webpack, docs:check и diff check прошли. Общие тесты проверяют клавиатурную очистку без submit, возврат фокуса, disabled, maxLength и внешний ref. Существующие feature regression tests сохранились.
- Во встроенном браузере все семь контекстов проверены на 1280×900 и 390×844: input radius 0, border 0, outline none, padding 10px 0; у wrapper единый зелёный контур, mobile font 16px. Кнопка очищает строку и возвращает фокус во всех контекстах. Ширина документа совпадает с viewport, переполнения нет.
- Выбор заданий на телефоне исходно давал поиску только 167px. Для сохранения читаемости его и параллель развернули на полную строку до 350px; тема/тип остаются рядом. После изменения повторно проверены layout, очистка и сборка.
- QA использовала отдельную вкладку, без изменения работ, назначения, учеников, выбранных прав или создания ключа; форма подключения закрыта отменой, выбор заданий закрыт возвратом. Исходная вкладка пользователя сохранена. Safari/Firefox отдельно не запускались.
- Ponystack-contract: один контролируемый компонент с семью вызовами, без общего query/state слоя, копии value, таймеров, дополнительных библиотек или изменения foundation tokens. Внешний inputRef оставлен для существующего восстановления фокуса. Lean already. Ship.
