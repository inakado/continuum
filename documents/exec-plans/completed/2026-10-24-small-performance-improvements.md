# PERF-01: три ограниченные оптимизации

Статус: Completed — реализация и локальная проверка, 24.10.2026. Основание — [аудит](../../research/2026-10-24-performance-audit.md). Пользователь поручил последовательно улучшить поиск банка, убрать лишний CSS и настроить сжатие JSON. Production-выпуск не входит в поручение; установленный серверный Nginx не изменён.

## Объём и порядок

1. Общий teacher-bank query hook: debounce 300 мс только изменяемой непустой строки, немедленный первый запрос/очистка, AbortSignal через transport. URL и экспорт используют актуальный ввод; конструктор сохраняет выбор.
2. Root layout: убрать неиспользуемые CSS Excalidraw и asset-path script, сохранить пакет/vendor и тему.
3. Nginx: gzip JSON только GET согласованных assessment namespaces, без auth/ключей/паролей и write-responses. Сохранить маршрутизацию, no-store и права.

Новые зависимости, миграции, API-пагинация, кеши и переделка макетов не требуются.

## Критерии и проверки

- Быстрый ввод даёт один GET после паузы; очистка, фильтры, initial URL, Back/Forward и экспорт корректны; устаревшие GET отменяются без пользовательской ошибки.
- Релевантные web-тесты, boundaries, typecheck и production build проходят; CSS chunk Excalidraw исчезает. Desktop/mobile просмотр обеих ролей.
- Реальный локальный Nginx принимает production template; gzip/identity дают одинаковый JSON, no-store сохраняется, POST/auth/key endpoints и binary не сжимаются. Server config не изменяется.
- SoR и roadmap обновлены; сравнение до/после и ограничения записаны здесь.

## Решения и риски

- Query key содержит текущие фильтры, запрос временно disabled до паузы: не показывать результаты старой строки как результаты новой. Начальная загрузка/очистка без задержки. Прежний loader остаётся.
- Nginx проверяется через временное локальное окружение, без production нагрузочных запросов. При будущем выпуске установленный конфиг нужно обновить отдельно и проверить `nginx -t` перед reload.
- Rollback: вернуть изменения hook/transport и root layout, прежнюю Nginx-конфигурацию; данные/БД не затрагиваются.

## Прогресс

- Поиск реализован в прежнем `useTeacherBank`, без дополнительного слоя состояния результатов. Три новые transport/query регрессии проверяют initial URL, одно обращение после быстрого набора, немедленную очистку/фильтры/страницы, переданный signal и отсутствие позднего результата отменённого запроса. Прежние тесты проверяют URL/Back/Forward, фокус/очистку и выбранные версии в конструкторе. Релевантный набор: 47/47.
- Удалены только root CSS import и asset-path script Excalidraw. Пакет, vendor-sync и тема сохранены. Сумма CSS chunks production-сборки: **299 161 → 157 036 байт**, разница **−142 125 байт**; удалённый chunk локально gzip занимал **22 158 байт**. Chunks с Excalidraw после сборки отсутствуют. Это размер артефактов, не замер загрузки браузера по сети.
- В шаблоне Nginx добавлены allowlist GET namespaces, `gzip_types application/json`, порог 1024, `Vary` и сохранённая работа с `no-store`. В записи, auth, учеников/пароли и reviewer-access compression отключён, в бинарные типы не включён. `if` содержит только поддерживаемую Nginx gzip-директиву, маршрутизация/proxy_pass остаются прежними.
- `node --test deploy/scripts/test-nginx-gzip.mjs`: **17/17**, production template проходит `nginx -t` в одноразовом локальном Nginx. Пять JSON reads: **2651 → 210 байт**, распаковка побайтно равна identity; URI/query и `no-store` сохранены. Проверены не-GET, auth/key/password paths, соседний неподходящий prefix, image MIME, малый JSON, 403 и `/api/internal/` 404. Синтетика не является коэффициентом сжатия настоящего отчёта. Контейнер/сертификат удалены после теста.
- `pnpm --filter web test`: **66 файлов, 225/225**; `pnpm lint:boundaries`, `pnpm --filter web typecheck`, `pnpm build:web` проходят. JSDOM сообщает существующий `Window.scrollBy not implemented`, падений нет.
- Встроенный браузер: teacher bank, поиск/очистка и предпросмотр с формулами/таблицей; login, student materials и пустой student works. Проверены desktop банка (обычный viewport около 1106 px), student materials 1280 px и mobile 390×844. Стили, фокус поиска, меню/формы и структура каталога сохранены. Временный viewport override сброшен.

## Task-specific troubleshooting

Первый Nginx fixture использовал слишком длинный literal в `return`; уменьшен до 2651 байта, production template не был причиной ошибки. Затем обнаружена гонка старта одноразового контейнера — добавлен ограниченный retry только `ECONNREFUSED` до запросов проверки. В тесте отмены TanStack потребовался отдельный tick уведомления после включения query; код приложения из-за этой тестовой ошибки не менялся.
