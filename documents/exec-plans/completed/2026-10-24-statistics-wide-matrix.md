# Плотная матрица результатов для длинных работ

Статус: Completed.

## Цель и границы

Плотная teacher-матрица на 20+ заданий: фиксированная ширина имени и задач, горизонтальный скролл, закреплённые имя слева и итоги справа. Номер задания в одну строку, максимум в подсказке/условии; баллы `1/2` без переноса. Никаких новых библиотек, миграций, student UI и пересчёта результатов.

## Решения

- Имя 200px, класс 80px, задача 56px, каждый итог 84px. Слева фамилия/имя, справа существующие части/итог; размеры не растягиваются при небольшом числе заданий. На узких экранах закреплены только имена (160px), правые итоги доступны прокруткой и не перекрывают задания.
- `StatisticsStudent.displayName` — аддитивная необязательная read-проекция фамилии/имени из явных полей профиля, без отчества и угадывания порядка слов. При отсутствии профиля — снимок логина. `name` снимка сохраняется для истории/панели/CSV. Матрица сортирует краткие подписи по алфавиту, поиск учитывает также исходное ФИО и логин.
- При отсутствии окончательного результата в узкой ячейке прочерк, состояние доступно в имени кнопки/подсказке и в прежней панели ответа. Ноль остаётся числом; итоги не пересчитываются.
- [AG Grid: Column Pinning](https://www.ag-grid.com/javascript-data-grid/column-pinning/) — знакомый паттерн левой идентичности/правых итогов и сохранения доступной центральной области; реализация штатным CSS sticky, без установки grid-библиотеки.

## Проверки

Shared/web typecheck, Docker API build и HTTP-регрессии имён/прав; web tests/boundaries/build; docs/diff. Встроенный браузер на временной работе 20×20: горизонтальная/вертикальная прокрутка, позиции закреплённых колонок, один/два блока, 1280/1920 и базовая mobile-проверка. Только собственные временные данные, после QA удалить.
