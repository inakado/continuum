# Единая прокрутка банка и выбора заданий

Статус: Completed.

## Цель и границы

Распространить проверенный layout импорта на банк, подбор заданий в работу и просмотр выбранного набора. Список и условие прокручиваются независимо; список и чекбоксы сохраняются при выборе; новое условие открывается сверху. Геометрия и доступность задаются одним role-neutral CSS Module. Без изменения данных, API, фильтров и закреплённых версий.

## Порядок

1. Зафиксировать регрессии позиции списка, сброса условия и фокуса навигации.
2. Вынести bounded workspace, колонки и scroll-области в общий CSS Module; перенести импорт на него без дублирования.
3. Сохранить toolbar/pagination вне прокручиваемого условия, мобильный переход «список ↔ условие» и режим разворота.
4. Проверить обе новые поверхности, импорт, выбор чекбоксов, desktop/mobile; boundaries, web tests, typecheck, build и docs.

## Риски и откат

Не remount-ить всю правую колонку: это теряет фокус кнопок навигации и возврата. Ключ меняется только у scroll-области условия. Не сбрасывать scroll списка при preview/checkbox updates. Изменения ограничены CSS, разметкой и regression tests; несвязанный working tree сохраняется.

## Завершение

Все три сценария используют один CSS Module без новых зависимостей и JS scroll effects. По замечанию пользователя добавлен зазор 24px перед разделителем (16px до 1150px), чтобы счётчик и строки не прижимались к границе.
