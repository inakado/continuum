# Правильные ответы завершённого теста

Статус: Completed (локальная реализация). Дата: 31.10.2026.

## Согласовано

Перенести выбранный макет в student-контур для short_number, short_text, single_choice, multiple_choice и matching. Оставить собственный ответ в поле/выборе; под ним состояние, точные баллы и правильный ответ при неполном результате. Полностью верный ответ не дублировать. Поддержать работы только с тестом и смешанные работы. Ключи доступны только после завершения тестовой части, без отдельной публикации преподавателем. Extended/PDF-проверка сохраняет свой lifecycle.

## Контракт и границы

Добавить отдельный nullable-free answerKeys map в завершённое StudentAttemptState, не добавлять grading/solution в PublicAssessmentItem. Строить ключи из того же эффективного снимка с явными исправлениями оценивания, что использует оценщик. До completed поля нет ни в detail/start/save, ни в summary. Завершение/повтор и повторный вход возвращают согласованные баллы и ключи; чужие назначения недоступны. Один канонический допустимый текстовый ответ достаточен; допуски и полные критерии остаются на сервере.

UI — только features/student-works; общий teacher renderer и teacher preview не менять. StudentReviewedQuestion переиспользует нейтральные Markdown/поля. Скрывать подсказки формата только в завершённом просмотре. Проверить обновление ключей при исправлении уже оценённой задачи.

## Проверки и завершение

Shared contracts/typecheck, API typecheck в Docker, targeted HTTP/БД/S3 тесты изоляции/всех типов/исправлений; student tests, web typecheck, lint:boundaries. Браузерная проверка 390/desktop и всех состояний через реальные компоненты/API. Обновить SoR/roadmap, удалить временные feedback-модули, вкладку и route; сохранить только проверяемые локальные screenshots. Production/deploy не разрешён этой задачей.

## Риски и откат

Не смешивать auto-completion с публикацией extended/PDF. Не отдавать весь grading объект и не отправлять ключи незавершившему ученику. Ответы учащихся и снимки версий не менять. Изменение additive, миграции БД для него нет; откат UI/transport оставляет исходные результаты.
