# Четыре небольших UX-доработки и визуальный проход

Статус: завершено локально. Без commit/push/deploy.

## Scope и порядок

1. ЕГЭ и точный provider в выборе заданий конструктора: существующие API/query/источники, сохранение выбранных версий, сброс страницы, очистка темы/source при смене параллели.
2. Сброс пустого отфильтрованного банка в picker: очистить поиск/тему/тип/ЕГЭ/provider и страницу, оставить выбранную параллель и выбранные задачи.
3. Повтор read-загрузки условия в банке и preview ZIP: существующий refetch без нового импорта, сброса выбора и подтверждения записи.
4. URL-контекст списка работ (search и show=archived): reload/Back/Forward и возврат из работы без потери контекста. Search заменяет history, архив добавляет. Невалидные значения безопасно приводятся к текущим работам.
5. Desktop/mobile проход select, длинных названий, меню и клавиатуры. Исправлять только воспроизведённые дефекты в затронутых контурах, не менять глобальную тему.

## Проверки и ограничения

Component и hook regression: совместные фильтры, пустой сброс с сохранением selection, два read retry, URL round-trip/история. Boundaries/typecheck/web tests/build/docs. Браузер 1280/390: подбор, пустая выдача, возврат/обновление, select/длинные значения и фокус меню. Записи в пользовательские работы и production не нужны.

## Риски и откат

Не переимпортировать ZIP при повторе условия, не очищать selection при сбросе фильтров. Не добавлять локальный snapshot server state или новую query инфраструктуру. API и схемы БД не меняются. Откат только файлов этой работы, остальные локальные изменения сохраняются.

## Прогресс

- Пункты 1–4 реализованы по порядку. Picker передаёт exam/provider, reset не меняет selection/параллель. Read retry не перезапускает импорт. Список работ хранит контекст в URL и передаёт whitelist параметров в ссылку редактора; «К работам» возвращает их после прежнего safe-leave flush. Для useSearchParams страница списка обёрнута Suspense.
- Визуальный проход выявил и устранил три мелочи: выбранная тема пропадала из вариантов во время refetch (теперь сохранена в двух фильтрах); длинные select без ellipsis (добавлен); ширина параллели 130px резала «10–11 классы» (увеличена до 160). Дополнительно воспроизведён CSS-конфликт focus background меню работ: белый общий фон перебивал зелёный, selector усилен до role+data-highlighted. Меню ученика уже корректно и не менялось.
- Web 200/200; новые проверки фильтров, selection при reset, двух read retry, context link и hook URL/remount/Back/Forward, сохранения темы при refetch. Boundaries, web typecheck, scoped ESLint, финальная сборка Webpack, docs:check и diff check прошли. Прежний BankImportPanel complexity 21 остаётся; picker разложен без роста complexity и проходит scoped lint без предупреждений.
- Браузер: 1280×900 / 390×844, новые фильтры, пустой набор и reset с checked selection, длинная тема и заголовки задач. Ширина документа равна viewport; final grade width 160, mobile select padding-right 40/radius 2, text-overflow ellipsis. Список работ: search при явном возврате, show=archived после reload, Back. Меню работ и учеников: Enter/стрелки, различимый фон, Escape и возврат trigger; mobile menu не выходит за экран. После исправления фон меню работ подтверждён rgb(238,246,242), пункты radius 0.
- Retry ошибочного HTTP-условия проверен компонентными тестами; реальный API специально не отключался. Ложные сетевые сбои и потеря связи в браузере не эмулировались. Safari/Firefox и искусственные сверхдлинные авторские данные отдельно не запускались; использованы реальные длинные темы/задачи.
- QA в отдельных вкладках, без добавления заданий в работы, архивирования, удаления, изменения учеников или ключей. Исходный пользовательский экран и ввод сохранены. Обновлены SoR и roadmap.
- Ponystack-contract: существующие query/refetch/URL-паттерны, без нового API, миграций, browser storage и зависимостей. Отдельный PickerEmpty и render fallback уменьшают complexity; return URL строится только из двух разрешённых полей. Lean already. Ship.
