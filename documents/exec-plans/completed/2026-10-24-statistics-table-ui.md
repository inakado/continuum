# Табличная статистика по утверждённому макету

Статус: Completed.

## Цель и границы

Заменить высокие блоки статистики плотной таблицей по утверждённому `output/statistics-table-prototype/index.html`. Только teacher UI; API, знаменатели, записанные результаты и student-сценарий сохраняются.

## Решения

- Одна строка задания около 47–48px, общие колонки баллов, «Макс.», «Учтено», «Без результата»; без графика и метаданных в каждой строке.
- Основной режим — процент учеников на каждом балле, переключение на количество. Неприменимый балл и отсутствие данных не становятся нулём. Колонки от 0 до максимума работы (как минимум 0–3); нестандартные максимумы не обрезаются.
- Поиск, сортировка по заголовкам; класс/режим/сортировка и прежние фильтры восстанавливаются из URL. ФИО и ответы туда не записываются.
- Нажатие группы открывает учеников справа, затем фактический ответ в той же панели; есть возврат, закрытие/Escape и восстановление фокуса. Условие/источник — в этой же панели по названию задачи.
- Сравнение классов использует те же балльные колонки. Сохраняется доступ к существующей сводке двух частей.
- Desktop — компактная таблица с общей шапкой; mobile — локальный горизонтальный скролл и закреплённое название без переполнения страницы. Матрица учеников также уплотняется.

## Референсы

- [Apple HIG: Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables): короткие строки, подробности по запросу, сортировка.
- [Shopify Polaris Table](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/table): общие заголовки, numeric alignment, минимум необходимых колонок.
- [Jobber Quotes Report](https://help.getjobber.com/en/articles/quotes-report/): фильтры и дополнительные сведения по запросу. Визуальные карточки и временные фильтры в наш сценарий не переносим.

## Шаги и проверки

1. Общая таблица распределений, сортировка/единицы, компактный shell страницы.
2. Боковая панель групп/условия/ответа; сравнение классов и матрица учеников.
3. Component/unit: смешанные максимумы, отсутствие/ноль, переключение единиц, сортировка, фильтры, переходы, URL и focus/Escape. `lint:boundaries`, web typecheck/test/build, docs:check.
4. Встроенный браузер desktop/mobile на длинном наборе; документация, очистка временных данных.

## Риски и откат

Большие максимумы дают широкую таблицу: скролл ограничен таблицей. Смена макета не меняет серверную статистику. Откат ограничивается teacher-statistics и документацией; никаких миграций и новых зависимостей.
