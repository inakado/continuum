# Массовое удаление и отмена

Статус: Completed.

## Цель
Чекбоксы и единая компактная панель массовых действий в банке и учениках. Выбор всех ограничен текущей страницей/видимым списком; смена фильтра сбрасывает выбор. Перед записью — подтверждение количества; после — постоянная отмена всей операции без таймера. Существующая геометрия и прокрутка сохраняются.

## Решения
- Источники: [Carbon](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines), [Shopify](https://shopify.dev/docs/apps/build/app-home/migrate-from-polaris-react/unstable-bulk-actions), [Material](https://m3.material.io/components/snackbar/overview).
- Нативные checkbox, mixed-состояние выбора всех, отдельный просмотр строки. Панель появляется в контексте списка, без floating overlays.
- Batch API атомарны, ограничены 100 уникальными ID, с revision checks и безопасным повтором. Ошибка сохраняет выбор и undo receipt.
- Ученик удаляется обратимо: скрытие, блокировка входа/отзыв сессий; пароль, класс, доступы и результаты сохраняются. Отмена возвращает прежнюю активность. Старый single endpoint переводится на тот же механизм; удаление класса не меняется.
- Никаких реальных учеников/задач не удалять при browser QA. Запись/отмена проверяются на изолированных integration fixtures с cleanup.

## Проверки и завершение
Contracts, backend Docker typecheck/integration, component regression tests, boundaries, web typecheck/build/tests, docs. Встроенный браузер desktop/mobile, выбор/подтверждение/отмена диалога без записи пользовательских данных. После проверки перенести в completed.

## Результат и проверки 2026-10-28

- Добавлены teacher-only `BulkActionBar`, `SelectionCheckbox`, `BulkUndoNotice` и `useBulkDelete`, подключены к банку и ученикам. Нет новых зависимостей, карточек или floating-панелей. Номера строк заменены чекбоксами; плотность списка/предпросмотр сохраняются.
- Контракты batch delete/restore ограничены общей `BULK_ACTION_LIMIT=100`; API выполняет каждую группу одной транзакцией с lifecycle CAS и безопасным повтором. Старая одиночная логика банка переиспользуется.

- Встроенный браузер: 1440/1024/390/320px; без горизонтального overflow. На 320px панель остаётся одной строкой высотой 52px. ## Откат

Функционал локальный, без push/deploy. Добавочные nullable поля и revision можно оставить при откате кода; не удалять данные миграцией автоматически. Если до отката были реальные удаления учеников, сначала восстановить скрытые профили через lifecycle API, чтобы старый код не показал их просто отключёнными. Существующая отдельная операция удаления класса не меняет своего подтверждения; уже скрытые ученики из неё исключены.
