# Классификация заданий и происхождение

Статус: завершено локально. Без commit/push/deploy.

## Цель и границы

Разделить формат ответа `type`, принадлежность ЕГЭ `source.exam`, вид источника `source.kind` и правило `grading.policy`. Использовать существующие ZIP/версии и «Источник и сведения», без новых экранов, фильтров и миграций.

## Решения

- `source.exam`: `ege` / `none`; для явного ЕГЭ обязательны год и номер, для `none` они запрещены. Правило ЕГЭ несовместимо с `none`. Метка ЕГЭ не включает оценивание автоматически.
- `source.kind`: `taskbook` / `platform` / `original`. Название задачника обязательно в `collection`; `provider` — автор/платформа/«Авторское». Новые поля необязательны для совместимости, без defaults и переписывания существующих JSON/hashes.
- Инструкция агенту требует явной классификации новых пакетов. Недостающие сведения не выдумываются. Старые задачи с парой год/номер показываются как ЕГЭ; остальные без метки — «Не указана», а не ложное «Не ЕГЭ».
- Один source-контракт для пакета и summary/preview импорта предотвращает потерю метаданных при parsing. Исходный пилот не меняется; пример ege-v1 получает новые поля. Импорт изменённых метаданных создаёт новую версию; старые назначения сохраняют снимок.

## Проверки и критерии готовности

Shared-проверки сочетаний и legacy JSON; component-проверки сведений ЕГЭ/авторского/задачника; HTTP импорт/list/view/export/reimport без потери полей; typecheck, сборка, boundaries, docs, desktop/mobile. Ни одной новой настройки ученику.

## Риски и откат

Формат ответа не доказывает принадлежность ЕГЭ, вид источника не доказывает её тоже: авторское задание может быть ЕГЭ. Автоматического backfill и смены правил проверки нет. Откат только изменений этой задачи, без затрагивания остальных локальных работ.
