# UX-01. Безопасный уход из конструктора

Статус: реализовано и проверено локально 2026-10-24. Commit/push/deploy не выполнялись.

## Цель и границы

Дождаться сохранения ввода до debounce и текущего запроса перед ссылками, возвратом, logout и Browser Back/Forward. При ошибке сохранять редактор и давать остаться/повторить/явно отказаться от неподтверждённого ввода. Сохранить CAS/requestId, не добавлять browser storage, новый API и общий offline-режим.

## Порядок и приёмка

1. Regression для flush до таймера, единого in-flight и изменений во время записи.
2. Последовательный flush/discard в teacher draft; общий navigation guard извлекается из существующего student hook без изменения его поведения.
3. Подключить ссылки, кнопку возврата, logout, history; компактный диалог только при ошибке. Истёкший вход восстанавливается в текущем редакторе только под тем же teacher.
4. Проверить медленную запись, повторные клики, сеть, 401/409, отмену и discard; unit/component, типы/boundaries, сборку и доступную browser QA.

## Решения, риски и откат

- Серверные контракты не меняются. Неизвестный результат повторяется с прежним requestId; 409 не перезаписывается автоматическим retry.
- Ученический hook содержит role-neutral save-before-leave/history orchestration: перенос в lib с compatibility re-export оправдан общей причиной, без teacher/student cross-import.
- Нельзя отменить уже совершённый сервером commit при потере ответа. Discard прекращает будущие записи этой вкладки, а не откатывает подтверждённые изменения. Аварийное закрытие мобильной вкладки остаётся ограничением платформы.
- Откат только файлов этой работы, без сброса остальных локальных изменений.

## Проверки и прогресс

Начальные дефекты подтверждены по `use-work-draft`, `WorksShell` и `RoleGuard`. Новые regression-тесты flush сначала падали на отсутствующем методе; проверки UI/повторного входа добавлены после реализации.

- `useWorkDraft` объединяет таймер и принудительный flush: один in-flight Promise, последовательное сохранение новых правок после подтверждения прежних. При явном discard/unmount новые запросы и поздние cache updates прекращаются. Offline-запросы не зависают в paused mutation: `networkMode: always` возвращает ошибку обычным путём.
- `WorksShell`, возврат и `ContinuumHeader.beforeLogout` используют общий guard. История вынесена из student feature в `lib/navigation`, прежний student export сохранён. Новый API, БД и зависимости не требуются.
- `WorkSaveFeedback` содержит компактный диалог ошибки и восстановление сессии. `RoleGuard` сохраняет только уже авторизованный teacher editor с UUID; `WorkReauthenticate` проверяет исходный principal/роль, очищает поле пароля и не переносит форму в другой аккаунт. Конфликт 409 требует явной загрузки актуальной версии с прежним подтверждением.
- Unit/component: 177/177 web-тестов, 54 файла. Покрыты flush до debounce, ввод во время записи, dedupe, точный повтор неизвестного результата, logout, stay/retry/discard, 401 с сохранением/последующим уходом, 409, поздний ответ после discard, owner/role при входе. Существующие тесты history проверяют Back/Forward и повторный Back до ответа; student regressions прошли.
- `pnpm lint:boundaries`, web typecheck и `pnpm build:web` прошли. Web ESLint: 0 ошибок, 8 существующих complexity warnings; сложность `WorkEditor` уменьшена с 28 до 25, новые функции ниже порога.
- Встроенный браузер, dev `teacher1`: Back при невалидном несохранённом названии возвращает диалог, «Остаться» сохраняет ввод; logout при той же ошибке не завершает сессию; явный отказ позволяет вернуться к списку. Desktop и 390×844: диалог без переполнения, начальный фокус на «Остаться», кнопки переносятся строками. Viewport сброшен. Существующее название/состав работы на сервере не менялись.
- Автоматическая проверка отклонила QA-запись в существующую работу. Использована безопасная альтернатива: браузерная проверка без серверных изменений, успешная/медленная запись и восстановление входа проверены компонентными тестами. Это не browser end-to-end проверка сетевого обрыва, принудительного истечения cookie или реального мобильного браузера.
- Contract gate: speculative layers не добавлены; сохранён один history engine, отдельный компонент формы входа ограничивает auth/UI ответственность. Нового локального хранения черновиков нет.
