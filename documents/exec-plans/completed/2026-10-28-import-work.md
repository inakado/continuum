# Работа из импортированного пакета

Статус: Completed. Локально реализовано; production не менялся. Пользователь согласовал необязательное создание работы после импорта из всего пакета, включая неизменённые задачи.

## Цель и границы

Задачи сначала сохраняются в банк. На результате импорта вторичная кнопка создаёт заполненный черновик и открывает существующий редактор названия/порядка. Импорт и создание работы — независимые операции. Назначение классам, student, новые таблицы и production вне scope.

## Порядок и решения

1. Confirm сохраняет упорядоченные `{taskId, version}` и параллели пакета в result; старые результаты читаются без выдумывания версий.
2. Существующий create получает необязательный начальный items: атомарная проверка владельца/доступности и подсчёт баллов. Повтор UUID возвращает прежнюю работу без переинициализации.
3. На результате импорта сохраняется основной возврат в банк; создание работы — только явным нажатием. Одна параллель определяется автоматически, смешанные требуют выбора.
4. Полностью неизменённый пакет тоже можно подтвердить и использовать. Порядок манифеста и версии confirm сохраняются.
5. После создания — существующий редактор с фокусом названия; очистка preview не блокирует переход. Сбой создания оставляет успешный импорт.

## Риски и откат

История импортов остаётся временной; восстановление CTA после reload не обещается. В новый черновик нельзя молча пропускать удалённые задачи. Откат UI не требует миграции: прежние запросы create без items поддерживаются.

## Готовность и проверки

Shared boundary tests; PostgreSQL tests confirm → seed, unchanged, order/pinned versions, ownership/deletion, atomic rollback и повтор после редактирования. Web tests optional CTA, retry/same UUID, переход, mixed grades и title focus. Boundaries, web typecheck, backend typecheck только Docker, docs:check. Визуальная проверка desktop/mobile.

## Результат и проверка

- Добавлены закреплённые версии/параллели confirm, общий schema ссылок и начальный items в существующем create без миграций/зависимостей.
- Результат импорта предлагает вторичное создание работы из всего пакета; неизменённый пакет допускает «Продолжить». Переход в обычный редактор выделяет название, порядок/автосохранение сохраняются.
- 106 релевантных web-тестов, 56 shared-тестов, 89 API unit-тестов прошли. 3 интеграционных теста PostgreSQL выполняют реальный parse/confirm ZIP и seeded create: pinned версии, unchanged, порядок mixed types, сохранность банка/изображений, атомарный отказ, чужие/удалённые задачи, double create и retry после редактирования. В этих тестах storage — контролируемая память, не live S3.
- Web/shared typecheck, backend typecheck в Docker, boundaries, docs:check и diff --check прошли.
- В браузере проверены production React-компоненты результата и редактора на данных подготовленного пакета из 30 задач: desktop и viewport 375 px, переход с 22 автоматическими + 8 extended, title focus, изменение названия, перестановка и автосохранение. Shell и HTTP-ответы в временной компонентной проверке изолированы; это не авторизованный production smoke.
- Временный Vite-сервер остановлен, проверочный каталог удалён. Отдельный согласовательный прототип не создавался.

Финальная синхронизация generated-документов также отразила уже присутствующие параллельные правки StudentProfile и bulk routes; их реализация не входит в эту инициативу. После генерации общая docs:check прошла.
