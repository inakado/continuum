## Границы и решения

- Только библиотека владельца-преподавателя; банк, назначения, ответы и рецензии не меняются.
- Удаление PDF очищает все версии выбранного типа (`pdf` или `tasks_pdf`), остальные типы сохраняются.
- Занятие удаляется со всеми файлами; раздел — со всеми занятиями и файлами.
- Подтверждение фиксирует список версий/занятий. Изменение состава возвращает 409, требует нового подтверждения.
- Блокировки родителей сериализуют удаление с созданием занятия и завершением загрузки.
- Очистка S3 идёт после commit через `LibraryAssetDeletion`: повтор раз в минуту, до 20 записей за проход. Общие assets с живыми ссылками сохраняются.
- Диалог белый, компактный, с явным составом удаления, начальным фокусом на отмене и блокировкой повторного запроса.

Готово после проверенного production-выпуска. Пользовательские материалы для проверки не удалять.

## Риски и rollback

- Удаление необратимо в приложении. Откат кода не возвращает удалённые материалы; backup БД сам по себе не восстанавливает удалённые S3-файлы.
- При сбое S3 запись уже скрыта из приложения, физическое удаление повторится. Ранее скачанные файлы отозвать невозможно.
- Миграция аддитивная; для отката приложения оставить таблицу очереди и вернуть предыдущий SHA/API image по deploy runbook.
