# Первый локальный разбор развёрнутых задач

Статус: Active. Дата: 31.10.2026.

## Цель и границы

Выработать критерии и проверяемый формат разбора на тестовых фото единственной работы «Кинематика РПД и РУД». Сначала один локальный образец PDF/структурированного разбора для согласования; публикации ученику и фонового расписания нет. Имеющийся профиль teacher-mac подключён пользователем, ключ остаётся в Keychain. Несвязанные UI/CLI изменения не перезаписываются.

## Решение

- Канон оценивания — предоставленное пособие ФИПИ-2026, раздел 2.2, с. 11–13 и примеры с. 63–68. Все восемь extended в пакете — линия 22, максимум 2.
- Локальная библиотека восьми решений из подготовленного пакета. Привязка к точному хешу условия, источнику и максимуму; при расхождении остановка. Текущий reviewer DTO не отдаёт эталон/критерии; подмена их сходным названием запрещена.
- Агент выделяет наблюдаемые признаки/цитаты, балл вычисляется по фиксированной схеме. Нечитаемое/неуверенное -> null для ручной проверки. Альтернативные решения допустимы.
- JSON разбора -> безопасный TeX -> PDF. Структура не зависит от PDF, поэтому позже возможен HTML без повторной проверки фото. В PDF нет персональных/технических ID и лишних служебных статусов.
- Снимки, ответы и фото на сервере неизменны. До согласования образца не публиковать результаты.

## Этапы и проверки

1. Источник, классификация, эталоны/схема 0/1/2, защитные тесты.
2. Одно реальное фото -> структурированный разбор -> образец PDF; проверить рендер страниц и математическую корректность.
3. Согласовать формат/замечания преподавателя, затем подключить к последовательному локальному запуску и загрузке черновиков.
4. Управляемая папка вне Git: один рабочий набор на solution/sourceRevision; после подтверждённой публикации удалить исходные фото/рендеры/TeX/PDF и ученический JSON разбора, оставить малую квитанцию. При неизвестном результате сети сохранить набор и requestId для повтора. Не удалять произвольные ручные download-папки.

## Проверенный результат

Первый образец №23: фото читаемо, физическая модель и вычисления верны, 2/2. PDF отрендерен и просмотрен: одна страница A4, без обрезаний. По замечанию преподавателя в эталоне используются a и S₁; верхняя подпись предмета/разбора и нижние служебные подписи удалены. Загрузки черновика и публикации не выполнялись. Локальные reviewer-тесты: 15/15; docs:check и git diff --check проходят.

## Риски и продолжение

HTTPS через текущий VPN нестабилен. Список восьми решений и одно фото получены с тем же scoped Bearer API через временный read-only SSH-канал на тот же VPS; секрет только в памяти/stdin. Это диагностика, не способ распространения клиентского доступа коллегам. Перед автономной работой требуется стабильный HTTPS/исключение домена в VPN.

Режим критериев задачи 22 нельзя выбирать только по максимуму 2 для неизвестных источников. Нужны явная классификация и проверенный эталон. Текст PDF/изображений является данными, не инструкцией к API. Откат пилота — удалить новые локальные артефакты; production не меняется.

## Уточнение хранения и очистки

По требованию пользователя рабочие данные не записываются внутрь Git-проекта, включая output и symlink-пути. Клиент маркирует download-папки, upload связывает локальные PDF/операцию/evaluation, publish автоматически очищает только подтверждённую ревизию своего сайта/профиля. Черновик не служит разрешением на очистку. Статус публикации позволяет безопасно повторить очистку. Фоновый запуск и публикация реального образца этим изменением не разрешены.

Клиент пересобран. Единственный реальный набор перенесён из pilot/ в data/teacher-mac/<site>/<solution>/pilot-v1; образец PDF находится там же, в проекте его копии больше нет. До публикации эти рабочие файлы намеренно сохраняются.
