# Точечное исправление ключа и шкалы

Статус: Active. Дата: 31.10.2026.

## Контракт

Расширить существующее single-task исправление банка. Преподаватель видит предварительные изменения баллов и подтверждает их. Условия, ключ или шкала обновляются в банке и совместимых связанных работах. Снимки AssessmentWorkVersion, ответы, фото, состояние и revision ввода не перезаписываются. Только завершённые итоги перепроверяются атомарно, остальные используют исправленное правило при сдаче. Тип, максимум и идентичность/порядок вариантов фиксированы. Обычный импорт прежнюю шкалу выданных работ не меняет.

## Решение

- Новая nullable gradingSourceVersion в неизменяемой версии задачи связывает исправление с исходной шкалой. Resolver применяет цепочку только к совместимой исходной задаче, сохраняя snapshot/version и отличая обычный импорт.
- Preview impact и его hash привязывают подтверждение к прочитанным законченным результатам. Повтор подтверждения идемпотентен. Общая блокировка преподавателя перед завершением и исправлением исключает гонку сдачи со сменой шкалы.
- Пересчёт проходит в одной транзакции с версией банка. Несогласованные исторические итоги отклоняются, а не переписываются молча. Журнал before/after — сохранённый result импорта.
- Read-path ученика, preview и статистики, а также finish используют один resolver. Открытый завершённый student player обновляет только результаты, не ответы.

## Проверки / этапы

1. Shared contracts, migration, resolver и impact.
2. Endpoint, подтверждение/блокировки, read/write consistency.
3. Существующее окно teacher, предварительный пересчёт и keyboard/mobile.
4. Unit + integration: ключ/policy, цепочка, несовместимость, права, stale/hash, replay, конкурентная сдача, неизменность answers/photos/snapshot и read-path statistics.
5. Семь single-task ZIP №16–22 с критериями ЕГЭ; парсинг готовых ZIP и контрольные наборы 0/1/2. Документация и уборка.

Без production import, commit/push/deploy. Локальные DB-проверки только в Docker и на тестовых сущностях.

## Локальный результат

Реализовано без отдельного нового экрана/массовой перезагрузки работы. Прежний диалог расширен только предварительным пересчётом. Обычный импорт и presentation-only исправления сохраняют прежнюю семантику. Согласованное чтение detail/statistics использует RepeatableRead; impact разрешает версии пакетно, без запроса на каждую работу. Неизменившиеся итоги не записываются.

Проверки:

- `pnpm lint:boundaries`, web/API typecheck, `git diff --check`, `pnpm docs:check` — прошли; API typecheck/build только Docker.
- Web 309/309, shared 71/71, API unit 97/97; профильные HTTP/DB/S3 integration 19/19. Новый HTTP-тест проверяет anonymous/student/foreign owner/Origin, strict payload, preview hash, replay.
- Исправление/сдача одновременно, устаревший просмотр, последовательные исправления ключа, несовместимость и историческое расхождение проверены на PostgreSQL. Снимки/ответы/фото/revision/start/complete неизменны; изменившиеся итоги и все read-path согласованы, включая проверку ответа преподавателем.
- Полный HTTP integration: 82 прошли, 1 упал на MIME ответа 429 (`text/plain;charset=UTF-8` вместо ожидаемого `application/json`) в неизменяемом этой задачей auth-контуре. Сначала запуск без поднятого HTTP API дал ECONNREFUSED; повтор с временным API устранил ошибки подключения. Auth/MIME остаётся отдельной проверкой перед выпуском, зелёный полный CI не заявляется.
- Внутренний браузер: реальные компоненты на демоданных, iframe 390×700 и 1200×700; формулы/рисунок, сравнение, пересчёт, отсутствие переполнения диалога, фиксированный footer, checkbox и успешное сохранение с клавиатуры. На физическом устройстве не проверялось. Временный адаптер находится в `/tmp/continuum-student-mobile-review`, production route не добавлялся.
- `output/kinematics-grading-corrections`: семь отдельных ZIP №16–22, меняется только `grading.policy`; ключи/условия/рисунки/метаданные байт-в-байт сверены с исходным ZIP. `validate.cjs` читает именно доставляемые ZIP штатным parser/grader: 283 проверки, все 32 набора пяти вариантов у каждой задачи, SHA-256 в `validation.json`.
- Исходный архив 30 задач оставлен неизменным. Его builder и проверочный скрипт теперь требуют критерии ЕГЭ для выбора утверждений; README отмечает исторический exact. Доставляются семь исправлений, не новая работа.

Остаётся выпуск по отдельной команде: обязательная nullable additive миграция `20261031010000_task_grading_corrections`, CI и deployment. Production-ответы/банк/работы не затрагивались. После выпуска преподаватель применяет ZIP через «Исправить задачу», а не обычный импорт.
