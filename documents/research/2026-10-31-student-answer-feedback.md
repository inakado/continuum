# Правильный ответ после завершения теста

Дата: 31.10.2026. Статус: выбранный макет перенесён в проект, временные исходники и route удалены.

## Решение пользователя

Показывать правильный ответ сразу после завершения тестовой части. Сохранить введённое значение в существующем поле и исходный выбор в вариантах/соответствиях; отдельная строка «Ваш ответ» дублировала бы их. Реальные ключи не должны попадать в ученический API до завершения попытки. Это уточнение будущего UX-05; прежний вариант отдельной учительской публикации разбора не принят для этого сценария.

## Что увидели в коде

StudentQuestionWorkspace сохраняет форму ответа, навигатор уже показывает баллы по задаче. AssessmentAnswerInput остаётся в disabled fieldset, учебные подсказки ввода также остаются после завершения. StudentAttemptReadService отдаёт только publicItem и taskResults, ключей нет. StudentWorkScreen для завершённой работы без extended показывает только сводный результат; для нового сценария нужен доступ к самим задачам после завершения.

## Макет

Исторический адрес удалённого макета: http://127.0.0.1:5186/feedback.html. Удалённые временные исходники: /tmp/continuum-student-mobile-review/feedback-*.jsx, feedback-data.js, feedback.css и feedback.html. Использованы действующие StudentWorksShell, StudentWorkQuestions, навигация, Markdown и поля ответа. Демоданные синтетические, API/БД не меняются. Переключатели «Телефон»/«Компьютер» — оболочка макета, не продуктовый компонент.

Под формой тонкий разделитель, состояние с иконкой и баллы. При ошибке/частичном ответе ещё одна строка «Правильный ответ». При полном балле одинаковый ключ не дублируется. В вариантах исходные отметки сохраняются, правильные и ошибочно выбранные варианты имеют слабую заливку и соответствующую иконку; без отдельной легенды. Подсказки ввода в завершённой задаче скрыты. Шесть случаев: число с ошибкой, верное число, частичный выбор, верный одиночный выбор, соответствия, пропуск.

Браузерная проверка: мобильный iframe 388 px внутренней ширины и desktop 1138 px — scrollWidth совпадает с clientWidth. Проверены навигация и bottom sheet, сохранённые поля/выборы, частичный балл 1/2 и корректный ключ, отсутствие дублирования при 1/1, пропуск. Скриншоты демоданных — output/answer-feedback. Макет удалить после переноса согласованного решения; не оставлять постоянный prototype route.
