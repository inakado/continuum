# Мобильный аудит учительских экранов

Дата: 30.10.2026. Проверены настоящие исходные компоненты на локальном стенде с синтетическими read-only данными; production API и хранилища не использовались. Это responsive desktop browser QA, не физическая приёмка iPhone. Student-контур не аудировался.

## Подтверждённые исправления текущего пакета

- Назначение: вариант A, один компактный список вместо вертикально распавшейся таблицы. На 390 px высота строки около 111 px без повторения класса и 135 px с классом; полное ФИО не обрезается. Сохраняются отсутствие части, незавершённый тест и независимость фото/проверки. Подробности — настоящий StudentSolutionsPanel, мобильный Dialog; закрытие вернуло фокус к тому же ученику.
- Статистика на 360 px: № 52 px, баллы по 58 px, заголовок/максимум скрыты только в этом представлении. Проверена прокрутка: левая координата заголовка первого балла и его ячейки совпали (−7 px), номер остался на 21 px. Исправлен обнаруженный пользователем selector: закрепление не затрагивает «0 б.» второго ряда. Номер открывает условие; отдельные баллы/группы, числовой поиск и pending защищены тестами.
- Там же исправлены поля: поиск был 13 px / 34 px, формат значений — 12 px / 36 px. Теперь шрифт 16 px, контейнер поиска и селекты 44 px; сам input внутри рамки — 42 px.
- Банк: старт/возврат дают 0 pressed и 0 checked. После отдельного checkbox — 0 pressed и 1 checked. В desktop 1200 px правый preview виден, стартовая строка сохраняет фон RGB 237/242/250. Мобильный подбор в работу не подсвечивает скрытый default preview.
- Контекстное меню работ при прокрутке блокировало body и уводило sticky-header до −719.5 px. После `modal=false` — header top 0, overflow-x clip, нет scroll lock, Escape возвращает фокус. Тот же исправленный pattern применён в teacher-меню банка, учеников и строк редактора. Подтверждения/формы остаются модальными.

## Где явного дефекта не найдено в проверенном сценарии

- Назначение классам: на 360 px таблица 320 px внутри рабочей области 320 px. Проверены «11А/11Б» и «11 А · Физико-математический профиль» — горизонтального переполнения нет. Состав раскрывается, отправка назначения не выполнялась.
- Подключение агента: 360 px, пять классов; форма не переполняется, поля 16 px / 44–46 px. Ключи не создавались, пароль не вводился.
- Desktop report 1200 px — одна таблица, мобильных строк нет; банк сохраняет split preview.
- У редактора есть touch-доступная альтернатива drag: «Выше», «Ниже», «На позицию…». Сам факт HTML drag не объявляется поломкой мобильного порядка.

Это не утверждение, что все комбинации и все экраны проверены. Остались реальные фото/PDF, системная клавиатура/поворот, физический PWA и состояния очень больших списков; проверять по отдельному воспроизводимому сценарию.
