# CONTENT

Статус: целевая content-модель активной переработки; legacy Course/Unit код удаляется по active plan.

## Scope

- возрастные группы `7`, `8`, `9`, `10–11`;
- разделы и занятия;
- draft/published lifecycle;
- PDF и интерактивные материалы с версиями;
- задачи с MathJax, изображениями и Excalidraw-диаграммами;
- защищённая выдача материалов ученику.

## Каталог

- `GradeBand` — фиксированная возрастная группа.
- `Section` — упорядоченная тема внутри `GradeBand`.
- `Lesson` — упорядоченное занятие внутри `Section`.
- `Task` — упорядоченный элемент занятия без progress/attempt state.

Ученик получает только опубликованные занятия в доступных ему группах, созданные преподавателем, который выдал этот доступ. Материалы другого преподавателя той же группы не видны. Direct URL не обходит access policy.

## Публикация

- Новая сущность создаётся как `draft`.
- Черновик доступен teacher preview и скрыт от student read-path.
- Публикация занятия и публикация версии материала — явные отдельные действия.
- Unpublish скрывает занятие, но не удаляет его и его assets.

## Материалы занятия

`LessonArtifact` является неизменяемой версией типа `pdf` или `interactive`.

- PDF загружается готовым и не компилируется сервером.
- Interactive artifact собирается локально и содержит проверяемый manifest.
- У занятия не более одной активной опубликованной версии каждого типа.
- Переключение активной версии атомарно.
- Предыдущие версии сохраняются для rollback до явной очистки.

## Задачи и диаграммы

- Текст задачи хранится в безопасном структурированном формате с MathJax delimiters.
- Изображения хранятся как отдельные assets.
- Excalidraw хранит editable scene JSON и статический SVG/PNG preview.
- Student payload не включает editable scene и не загружает Excalidraw runtime.
- Первая версия не хранит ответы, попытки, баллы или прогресс.

## Локальный authoring flow

1. Автор собирает PDF или интерактивную лекцию локально.
2. Publish client валидирует build output.
3. Готовый artifact загружается через защищённый upload flow.
4. Учитель проверяет preview и публикует версию.

Изменение контента не запускает platform build или deploy.
