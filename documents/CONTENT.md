# CONTENT

Статус: текущая content-модель библиотеки; будущие расширения — в [deferred roadmap](exec-plans/deferred-roadmap.md).

## Scope

- возрастные группы `7`, `8`, `9`, `10–11`;
- разделы и занятия;
- draft/published lifecycle;
- PDF и интерактивные материалы с версиями;
- задачи как готовый PDF-артефакт;
- защищённая выдача материалов ученику.

## Каталог

- `GradeBand` — фиксированная возрастная группа.
- `Section` — упорядоченная тема внутри `GradeBand`.
- `Lesson` — упорядоченное занятие внутри `Section`.

Ученик получает только опубликованные занятия в доступных ему группах, созданные преподавателем, который выдал этот доступ. Материалы другого преподавателя той же группы не видны. Direct URL не обходит access policy.

В ученическом каталоге название открывает страницу занятия, а «PDF» и «Задачи» сразу открывают соответствующий опубликованный PDF в новой вкладке, без второго нажатия на странице занятия. Перед выдачей временного URL API заново проверяет доступ; ссылка S3 не хранится в каталоге. Если браузер блокирует новую вкладку, файл открывается в текущей. Во время запроса повторное открытие заблокировано; при ошибке каталог остаётся доступным и позволяет повторить нажатие. Недоступный или удалённый файл не заменяется другим PDF занятия.

## Публикация

- Новая сущность создаётся как `draft`.
- Черновик доступен teacher preview и скрыт от student read-path.
- Публикация раздела и занятия — явные действия; публикация занятия активирует последние загруженные PDF конспекта и задач. Интерактивный ZIP остаётся черновиком до появления безопасного проигрывателя.
- Снятие с публикации пока не реализовано.

## Материалы занятия

`LessonArtifact` является неизменяемой версией типа `pdf`, `tasks_pdf` или `interactive`.

- PDF загружается готовым и не компилируется сервером.
- Конспект и задачи хранятся как два независимых PDF-артефакта с отдельными версиями.
- ZIP интерактивного материала можно хранить и скачать учителю, но безопасный проигрыватель и проверка manifest пока не реализованы; ученикам такой пакет не выдаётся.
- У занятия не более одной активной опубликованной версии каждого типа.
- Переключение активной версии атомарно.
- Предыдущие версии сохраняются до явной очистки; выбор прежней активной версии (rollback) в API/UI пока не реализован.

## Удаление

- Владелец-преподаватель может удалить PDF, занятие или раздел после подтверждения в интерфейсе.
- Удаление конспекта/задач PDF удаляет все версии только выбранного типа. Повторная публикация не возвращает старый файл; остальные материалы занятия сохраняются.
- Занятие удаляется со всеми версиями файлов, раздел — со всеми занятиями и файлами. Корзины и восстановления в приложении нет.
- Подтверждение передаёт `expectedIds`: версии файлов для PDF/занятия, занятия для раздела. Изменившийся состав возвращает `LIBRARY_CONTENT_CHANGED` (409); требуется закрыть диалог и подтвердить заново.
- Assets с оставшимися ссылками сохраняются. Для остальных удаление записи и постановка S3 key в `LibraryAssetDeletion` атомарны; физическая очистка выполняется после commit, при сбое повторяется раз в минуту (до 20 записей за проход, в том числе после перезапуска API).
- Банк заданий, назначенные работы, ответы и проверки не связаны с этим удалением и сохраняются. Ранее скачанные файлы отозвать нельзя.

## Задачи

- Задачи первой версии загружаются одним готовым PDF-файлом на занятие.
- Новая версия PDF не заменяет опубликованную до публикации занятия.
- Банк заданий, ответы учеников, проверка и баллы относятся к отдельному направлению [проверочных работ](exec-plans/active/2026-10-15-assessment-roadmap.md). Этот документ описывает готовые материалы занятия; структурированные задания банка не заменяют `tasks_pdf`.
- Excalidraw остаётся установленным для будущих авторских инструментов, но не загружается на student read-path.

## Локальный authoring flow

1. Автор собирает PDF или интерактивную лекцию локально.
2. Готовый artifact отправляется учителем в защищённый API, который потоково передаёт файл в object storage.
3. Учитель проверяет PDF и публикует занятие; интерактивный ZIP пока не проигрывается.

Изменение контента не запускает platform build или deploy.
