# Design System: Континуум

## Creative North Star

«Редакционный каталог физики»: спокойная белая поверхность, сильная типографическая иерархия, стальной синий акцент, тонкие разделители и высокая полезная плотность.

## Правила

- Списки и строки предпочтительнее сетки одинаковых карточек.
- На desktop основной каталог может быть двухколоночным; мобильная версия всегда одноколоночная.
- Карточка используется только для самостоятельного объекта или действия, а не как универсальная обёртка.
- Градиенты, glass, декоративный blur и крупные hero-блоки не являются частью продуктового языка.
- Цвет акцента обозначает действие, текущий выбор или публикацию; он не используется как фон ради декора.
- `Medeo Sans` — единое семейство основного UI, навигации, заголовков и подписей. Текстовый логотип входа и общей шапки использует прежний `Unbounded` 300; в рабочей шапке размер и разрядка компактнее. Onest не подключён. Иерархия основного UI задаётся размерами, весами и интервалами.
- Основное семейство выбирает `--font-ui` в `apps/web/app/globals.css`; все CSS Modules используют этот токен напрямую. Дополнительные семейства и совместимые алиасы Inter/Onest отсутствуют.
- Основной desktop shell фиксирует ритм выбранного макета: header `64px`, tabs `71px`, поля страницы `48px`, две равные колонки и строки каталога `37px`.
- Минимальная цель доступности — WCAG AA, явный keyboard focus и поддержка `prefers-reduced-motion`.
- Вход — отдельная полноэкранная композиция: центральная форма и адаптированный Iridescence React Bits в графитовой, серебристой и холодной синей палитре. Поля остаются светлыми, читаемость логотипа защищает затемнение по центру. Reduced motion останавливает движение; без WebGL остаётся статичный фон. Основные рабочие экраны сохраняют светлую редакционную поверхность.

## Основные композиции

### Student catalog

- компактный header;
- переключатель возрастной группы;
- разделы с заголовком и плотным списком занятий;
- в строке занятия видны название и доступные форматы: PDF, интерактив, задачи.

### Lesson view

- заголовок и компактная навигация назад;
- основной материал занимает максимальную ширину;
- PDF, интерактив и задачи переключаются без смешивания режимов;
- download является вторичным действием, просмотр — основным.

### Teacher materials

- список и редактирование разделены;
- статусы `Черновик` и `Опубликовано` читаются текстом, не только цветом;
- загрузка новой версии не скрывает активную опубликованную версию;
- destructive actions визуально отделены от основного сценария.

## Excalidraw

Excalidraw сохранён для будущего teacher authoring screen; действующего экрана редактора нет. Его runtime, CSS и asset-path script не подключаются глобально. Если такой экран появится, editor и стили загружаются в его контуре, а student получает статический SVG/PNG preview.

## Цвет и действия рабочих экранов

- Источник палитры — `--catalog-*` в `apps/web/app/globals.css`. Основной акцент `#445F92`, hover `#354D7B`, выбор `#EDF2FA`; контур действия и контур выбранной строки имеют отдельные токены. Цвет не дублируется в feature-модулях.
- Primary/secondary для банка, работ, классов, подключения агента и ученического выполнения используют общий `components/ui/catalog-action.module.css` через CSS Modules `composes`; размеры и layout остаются в features. Основное действие залито, вторичное имеет контур; inline-ссылки различимы подчёркиванием/контекстом.
- `--catalog-success` и `--catalog-success-surface` предназначены только для успешных результатов; ошибки/удаление используют danger. Цвет выбора не означает правильный ответ.
- Disabled имеет отдельные цвет текста, фон и контур; hover применяется только к доступным действиям. Focus видим с клавиатуры. Общие токены доступны портальным диалогам из root.
- Согласованный `/login` сохраняет собственную графитовую композицию и серебристый focus.
