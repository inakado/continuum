# KIN-01: импортируемая интерактивная лекция

Образец сохраняет авторский текст, 19 пронумерованных формул, семь демонстраций и самопроверку локального прототипа. Прототип и пакет используют одни компоненты содержания; копировать готовую страницу или её HTML вручную не нужно.

## Исходники

- Определение лекции: `apps/web/features/student-library/kinematics-package.tsx`.
- Содержание: `apps/web/features/student-library/KinematicsLessonContent.tsx` и подключённые тематические компоненты.
- Общий authoring kit: `apps/web/components/interactive-lesson/authoring/`.
- Общие правила: `documents/INTERACTIVE-LESSONS.md`.

## Сборка

Из корня репозитория:

```sh
node scripts/interactive-lessons/build-package.mjs
```

Результат — `output/interactive-lessons/kin-01.zip`. Рядом сохраняются распакованный HTML и manifest для локальной проверки. В ZIP ровно два файла: `manifest.json` и самодостаточный `lesson.html`. В HTML включены React, код моделей, CSS, геометрия, шрифты и подготовленные локальным MathJax CHTML-формулы. Интернет и библиотеки установленного приложения для исполнения пакета не нужны. Сервер не собирает и не выполняет исходники.

Сборщик принимает другой источник и выходной каталог:

```sh
node scripts/interactive-lessons/build-package.mjs path/to/lesson-definition.tsx output/interactive-lessons
```

Источник экспортирует `LessonDefinition`: стабильный `lessonId`, заголовок, контекст, идентификаторы статьи/заголовка, содержание разделов, версии вопросов и React-компонент `Content`. Текст и модели остаются авторским кодом, общий проигрыватель не знает о кинематике. У новой лекции должны быть собственные идентификаторы. При изменении смысла вопроса увеличить его `revision`, чтобы прежнее выполнение не подавляло новый вопрос.

Формулы, показанные первоначальным рендером, подготавливаются при сборке. Если новая модель требует вычисляемого TeX, нужен отдельный authoring-компонент с явным перечнем состояний либо расширение runtime; скрыто загружать MathJax из сети нельзя. Численные SVG-подписи текущих демонстраций вычисляются без TeX.

Сборщик проверяет внутренние ссылки и разделы, отказывает на ошибке MathJax и недостающем встроенном ресурсе. Перед передачей ZIP дополнительно проверить настоящий импорт и просмотр, мобильную ширину, масштабы и все состояния моделей по общему checklist. Одной успешной сборки недостаточно.

## Состояние читателя

Лекция исполняется в opaque sandbox. Она не читает cookie или localStorage платформы. Проигрыватель передаёт только масштаб и результаты перечисленных в manifest вопросов через версионированный контракт. Вопрос сохраняет точное сравнение с нормализацией внешних пробелов и регистра; оба проверенных результата прекращают автоматический показ. Встроенные вопросы не являются оцениваемой работой.
